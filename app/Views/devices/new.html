Install the Catch PWA

It opens like an app, keeps manual captures close, and queues work safely when your connection drops.

Open Catch Web App
  1. Open this page in your device browser.
  2. Use the browser menu and choose Install app or Add to Home Screen.
  3. Open Catch from the new Home Screen or app-menu icon.

On Android, the installed PWA also appears in the share menu for links and text.

Connect Catch CLI

Build the client, run its login command, and approve the short-lived request in the Catch tab it opens.

cd cli
go build -trimpath -o catch ./cmd/catch
catch login

The current CLI can read and search Catch. Capture commands for scripts are not included yet; use the API for write access.
