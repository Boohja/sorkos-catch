How to use it

  1. In Add to Catch, choose Phone or tablet and iPhone / iPad.
  2. Name the device and continue to its setup page.
  3. Create a temporary pairing code, then run Catch Setup on the iPhone or iPad you want to connect.
  4. Enter the code when the shortcut asks for it. The device will appear as connected in Catch.
